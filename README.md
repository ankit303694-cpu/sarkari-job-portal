# Sarkari Job Portal V7
Monetization-ready version.

Includes:
- AdSense-ready advertisement areas
- Sponsored/Featured section
- Affiliate/Recommended Resources section
- Basic monetization configuration
- Admin verification workflow
- Job search and categories

Configure `data/monetization.json` with your own legitimate ad/affiliate IDs and links.

Run:
```bash
npm install
ADMIN_KEY=your-secret-key npm start
```

No account or earnings are created automatically. Follow the policies of each advertising/affiliate platform.
